## Selected work

### GunKustom: CTO and co-founder (client work, 2024 to 2026)
Joined as senior backend engineer and was CTO within six months. Inherited a monolith that couldn't ship, got the team behind a full rebuild, and put v1 in production in twelve months. I designed and built about 90% of the backend: a hybrid NestJS and Python system that normalizes messy multi-format vendor feeds, with idempotent upserts and alias-driven matching that got more accurate with every feed. → [gunkustom.com](https://gunkustom.com)

### PowAlert: backend lead
Real-time snowfall alerting. MERN, resort-level weather ingestion, SMS and email alerts on user-set thresholds. The hard part was reliability at the edges: cron fetch cycles, 24-hour duplicate suppression, phone validation before the SMS provider, batched reads and writes. → [powalert.com](https://powalert.com)

### Willow Bend Family Clinic: production-shaped AI demo
A sanitized rebrand of a real client build. The LLM has no write path to appointments; a human stays in the loop by design. Care assistant with guardrails that falls back to an offline engine, so the demo never breaks. React, TypeScript, Firebase transactions with audit flags, Netlify Functions. → [willow-bend.netlify.app](https://willow-bend.netlify.app)

### ProForma: the AI business case
Open source, Apache-2.0. Turns a generative AI initiative into a 5-year cost, benefit and risk projection: payback year, ROI, NPV, IRR and peak funding. Runs in the browser with no account and no backend. 96 regression tests against a source workbook, so a refactor can't quietly move a number. → [github.com/MenokoOG/proforma](https://github.com/MenokoOG/proforma)

### Asymptote
Static time and space complexity estimator for Python, built for agents. Per-function Big-O with confidence, evidence, and the unknowns it can't decide. CLI, agent tool, or MCP server. v0.1.
